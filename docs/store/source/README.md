# Store Artwork Sources

These master PNG files are the reviewed sources for the Google Play icon and feature graphic:

- `catguard-store-icon-master.png` - square guardian-cat illustration with transparent corners;
- `catguard-feature-master.png` - wide three-defender key art with the Russian title.

`tools/store/generate-store-assets.ps1` center-crops and scales the masters to the exact Google Play output sizes under `docs/store/assets/`.

The illustrations were created with the built-in OpenAI image generation tool on 20 July 2026 and visually reviewed for subject clarity, title accuracy, safe margins, family-friendly content, and consistency with the repository-owned night-garden backgrounds. Keep the runtime screenshots separate and unedited so they continue to represent the actual application.
