# Procedural Audio

Phase 6 uses self-made procedural audio generated at runtime by `ProceduralAudioService`.

No external sound packs, paid assets, music files, or third-party audio files are included in this folder.

Current audio placeholders:

- simple UI click tone;
- tower placement tone;
- tower shot tone;
- enemy defeat tone;
- base hit tone;
- victory and defeat arpeggios;
- a very soft generated music loop.
