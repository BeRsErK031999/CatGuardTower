# Game Design Core Loop

## Core Loop

Поставил котов → отбил волну → заработал монеты → усилился → прошёл уровень → прокачал базу → вернулся завтра за наградой.

## Player Fantasy

The player builds a small cat defense squad, improves it between runs, and protects the base from increasingly tricky enemy waves.

## Base Towers

- Fast shooter cat: low damage, high attack speed, good early default tower.
- AoE cat: slower attacks, hits groups, useful against dense waves.
- Slow cat: applies movement slow, supports other towers and helps control fast enemies.

## Base Enemies

- Normal enemy: baseline health, speed, and reward.
- Fast enemy: low health, high speed, punishes weak path control.
- Armored enemy: high health or armor, tests sustained damage.

## Session Shape

A level should last about 5-10 minutes, with a clear win or loss result and a visible reason to upgrade before the next attempt.
