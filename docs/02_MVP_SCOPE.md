# MVP Scope

## Included In MVP

- Main menu.
- Level selection.
- Gameplay screen.
- 10-20 levels.
- 3 tower types.
- 3 enemy types.
- Win/lose state.
- Progression.
- Daily reward.
- Local saves.
- RU/EN localization.
- Firebase Analytics later.
- Rewarded ads later.

## Not Included In MVP

- iOS.
- Multiplayer.
- PvP.
- Server/backend.
- Clans.
- Chat.
- Forced interstitial ads.
- Paid assets.
- Complex story.
- 3D.

## MVP Success Signal

The MVP is successful when a player can complete short levels, return for progression, and the project is ready for analytics and voluntary rewarded ads without rewriting gameplay systems.
