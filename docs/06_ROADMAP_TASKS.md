# Roadmap Tasks

## Stage 0: Project Preparation

- Create Unity 2D project.
- Configure Android-first settings.
- Move `_project_scaffold/` into `Assets/_Project/`.
- Create Boot, MainMenu, and Level scenes.

## Stage 1: Playable Prototype

- Scene loading flow.
- Basic grid.
- Enemy path movement.
- One tower.
- One wave.
- Win/lose state.

## Stage 2: Towers And Enemies

- 3 tower types.
- 3 enemy types.
- ScriptableObject configs for stats.
- Basic balance pass.

## Stage 3: Progression And Saves

- Local save service.
- Level unlocks.
- Soft currency.
- Upgrade state.

## Stage 4: Daily Rewards

- Daily reward calendar or simple streak.
- Local validation suitable for MVP.
- Reward claim UI.

## Stage 5: Firebase Analytics

- Analytics wrapper service.
- Core events for session, level start, win/loss, upgrade, and reward claim.

## Stage 6: Rewarded Ads

- Ads wrapper service.
- Voluntary rewarded placement.
- No forced interstitial ads.

## Stage 7: Google Play Closed Testing

- Android build pipeline.
- Store metadata draft.
- Internal/closed testing track.

## Stage 8: Soft Launch

- Small audience release.
- Analytics review.
- Retention and monetization iteration.
