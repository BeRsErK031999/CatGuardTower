# Asset Pipeline

## First Stage Rule

Use only free, self-made, or placeholder assets that are safe for commercial use.

Do not add paid asset packs during MVP development.

## Visual Direction

- 2D portrait mobile readability.
- Clear silhouettes for cats, enemies, towers, and projectiles.
- UI should be readable on small Android screens.
- Prefer simple sprites over detailed art until gameplay is validated.

## Folder Targets

- Art sprites: `Assets/_Project/Art/`.
- Prefabs: `Assets/_Project/Prefabs/`.
- UI assets: `Assets/_Project/Art/UI/`.
- VFX: `Assets/_Project/Art/VFX/` and `Assets/_Project/Prefabs/VFX/`.
- Audio: `Assets/_Project/Audio/`.

## Naming Direction

Use descriptive English technical names for assets and keep player-facing RU/EN text in localization data.
