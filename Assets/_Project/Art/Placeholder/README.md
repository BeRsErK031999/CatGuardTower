# Placeholder Visual Assets

Phase 6 uses self-made procedural placeholder visuals generated at runtime by `PrototypeSpriteFactory`, `PrototypeLevelController`, and `SimpleVfxFactory`.

No external image packs, paid assets, or third-party art files are included in this folder.

Current visual placeholders:

- square tiles and backdrop patches;
- circle enemy/spawn/base markers;
- diamond tower and shot markers;
- lightweight expanding VFX bursts.
